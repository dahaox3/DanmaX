# 旧版 mpv 分支

此分支以 2026-10-17 的 554c74a 为基底，早于移除通用媒体会话入口的 d428344。保留原来的 SmtcReader、SmtcBackend、MediaMonitor 和 PlaybackSetupPane；未以新版播放器流程替代旧版。

在 mpv 中载入视频，再从 DanmaX 底部的“播放器”展开来源和播放方式，选择“跟随播放器”，在媒体会话列表选择 mpv.exe。加载弹幕后开始播放。mpv 必须继续提供此前可用的 Windows SMTC 会话；设置中的 PotPlayer/VLC 外部播放器预设与这份媒体会话列表是两个入口。

移植的三项改动：

- XML 小数字号校验后四舍五入为整数。
- 允许重叠仅作用于滚动弹幕与固定字幕之间；类内始终避让，顶部／底部固定字幕分别从对应边缘分配。
- 设置 → 弹幕播放中的帧率上限支持 0～1000，0 表示不限帧；保留基于实际经过时间的滚动和寿命计算。Qt 其他窗口有动画时仍可能重复呈现相同弹幕画面。

构建使用独立的 out/build/windows-legacy-release，避免复用新版构建缓存。项目工具链和依赖锁未改变，运行配置不放入版本控制。

验证记录：

- Release 编译成功；相关 CTest 15/15 通过（58.60 秒），包含 SMTC reader、VLC、工作流、XML、三种运行服务后端、渲染缓存、帧率、时钟、轨道、设置及隐藏播放。
- 应用原生启动 smoke 退出 0；7 条混合模式／小数字号 XML 全部在屏，丢弃 0。
- 本机正在运行的 mpv 保持原状态；只读发现报告中确实存在 mpv.exe 媒体会话。未对该用户播放器发送暂停、播放、跳转或关闭命令。
- 原生界面专项覆盖 mpv 会话的键盘选择与保存、144 FPS 设置输入及旧版已保存播放器工作流；证据保存在 out/validation/legacy-mpv/。具体结果以该目录中的最终日志为准，合成会话用例不等同于真实 mpv 全流程控制验收。

默认运行目录保留为 out/run/windows-release，部署时保留该目录中的设置、日志和缓存。其他 mpv 版本、用户自行停用 SMTC 的情况、长期性能及静态单 EXE 未新增验收。
